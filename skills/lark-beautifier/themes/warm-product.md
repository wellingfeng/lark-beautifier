# Theme: warm-product

## 设计 Token

| 角色 | 颜色 | 何处使用 |
| --- | --- | --- |
| primary | orange | 主标题、行动按钮强调 |
| accent | yellow | 次级强调、亮点 |
| success | green | 用户收益、转化提升 |
| danger | red | 痛点、问题、流失 |
| neutral | gray | 背景信息、可选项 |
| highlight | purple | 用户名、关键场景 |

## 行内强调规则

- 用户场景 / 角色：`<text color="purple">**新手买家**</text>`
- 业务指标提升：`<text color="green">**+15% 转化**</text>`
- 痛点 / 问题：`<text color="red">**流失率 23%**</text>`
- 关键卖点：`<text color="orange">**0 学习成本**</text>`

## Callout 配色映射

| 用途 | emoji | background-color | border-color |
| --- | --- | --- | --- |
| TL;DR | 🎯 | light-orange | orange |
| 用户故事 | 👤 | light-purple | purple |
| 痛点 | 😣 | light-red | red |
| 收益 / 成果 | 🎉 | light-green | green |
| 提示 / 建议 | 💡 | light-yellow | yellow |
| 节奏 / 迭代 | 🚀 | light-blue | blue |
| 备忘 | 📝 | light-gray | gray |

## 组件偏好

1. **cover-banner** —— 产品名 + 一句话价值主张
2. **kpi-card-row** —— 核心指标，3 列起步
3. **before-after** —— 改版前/改版后对比
4. **quote-block** —— 用户原话
5. **timeline** —— 上线节奏
6. **action-items** —— 行动项 + 负责人

## 反模式

- 不要用过于冷峻的蓝灰主题盖住产品的温度
- 不要在用户故事里穿插大段技术术语；术语放到「补充资料」callout
