# Theme: vivid-marketing

## 设计 Token

| 角色 | 颜色 | 何处使用 |
| --- | --- | --- |
| primary | purple | 标题、品牌强调 |
| accent | pink | 次级强调、热门标签 |
| success | green | 数据飙升、好评、爆款 |
| danger | red | 紧迫感、限时、警示 |
| highlight | orange | 行动号召、福利、按钮文字 |
| neutral | gray | 辅助信息 |

## 行内强调规则

- 大胆使用行内高亮（每段允许 2-3 处）
- 数字、价格、时间统一用强调色
- 关键词用粗体 + 颜色双重强调

示例：`<text color="orange">**限时 3 天**</text>`、`<text color="purple">**全网首发**</text>`、`<text color="green">**+10w 下载**</text>`

## Callout 配色映射

| 用途 | emoji | background-color | border-color |
| --- | --- | --- | --- |
| 头条 / TL;DR | 🔥 | light-orange | orange |
| 福利 / 限时 | 🎁 | light-red | red |
| 爆款 / 好评 | ⭐ | light-yellow | yellow |
| 案例 / 故事 | 📖 | light-purple | purple |
| 立即行动 | 🚀 | light-blue | blue |
| 数据亮点 | 📈 | light-green | green |

## 组件偏好

1. **cover-banner** —— 大图 + 大字号标题 + 行动号召
2. **kpi-card-row** —— 数据冲击，4 列，数字大、字小
3. **quote-block** —— 用户/媒体原话
4. **before-after** —— 改版前/改版后效果图
5. **action-items** —— 福利领取/参与方式

## 反模式

- 数据未经核实禁止包装为「爆款」「全网第一」
- 不要把所有段落都做成饱和色块 —— 留白是节奏
- 高管/合规/法律文档绝不使用此主题
